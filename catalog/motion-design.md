# Motion Design

## Use When

- Definir padrões de animação de um produto
- Revisar timing e easing de transições existentes
- Garantir suporte a prefers-reduced-motion

## Installation

```bash
npx skills add motion-design-skill
```

## Notes

Bom guia de princípios; não gera código de animação sozinho, funciona melhor combinada com a lib de animação do projeto.
